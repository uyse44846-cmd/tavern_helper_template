# 世界书递归配置修复报告

## 问题诊断

检查 [`index.yaml`](../src/佩伊洛/index.yaml) 发现以下条目**缺少递归配置**：

### 缺少递归配置的条目

1. **主线·二人的樱花**（第290-299行）
2. **主线·常乐谷之约**（第301-310行）
3. **主线·蔚蓝的归属**（第312-321行）
4. **主线·说不出口的那句话**（第323-332行）
5. **主线·情敌出现**（第334-343行）
6. **主线·自由事件引导**（第345-354行）

### 特殊条目

- **始终使用galgame界面**（第70-81行）：递归配置为 `false`，这是**错误的**

## 修复方案

根据世界书配置指南：
> 所有世界书条目必须同时勾选：不可递归 + 防止进一步递归
> 原因：防止绿灯激活绿灯，防止TOKEN爆炸。无论蓝灯还是绿灯都必须勾选。

### 需要添加的配置

所有缺少递归配置的条目都需要添加：

```yaml
递归:
  不可被其他条目激活: true
  不可激活其他条目: true
```

### 需要修改的配置

"始终使用galgame界面"条目需要将递归配置从 `false` 改为 `true`：

```yaml
递归:
  不可被其他条目激活: true  # 从 false 改为 true
  不可激活其他条目: true      # 从 false 改为 true
```

## 注意事项

1. **EJS动态加载不影响递归规则**：即使这些事件条目是通过 `getwi()` 动态加载的，它们的内容仍然会被插入到AI上下文中，如果内容中包含其他条目的关键词，就可能触发递归激活。

2. **所有条目无例外**：无论是蓝灯、绿灯、D齿轮位置、角色定义前后，所有世界书条目都必须勾选递归选项。

3. **分隔符条目例外**：使用锚点 `*分隔符` 的条目（如"===变量开始==="）已经继承了分隔符的配置，不需要单独配置。
