# 选择框强调条目创建指南

## 目的

确保AI在每次回复中都输出选择框（roleplay_options），避免遗漏。

## 创建步骤

### 1. 创建选择框强调文件

在 [`src/佩伊洛/世界书/`](src/佩伊洛/世界书/) 目录下创建文件 `选择框强调.txt`，内容如下：

```yaml
---
选择框强调:
  rule:
    - by recalling `选择框` document, you must output the roleplay options wrapped in <roleplay_options> tags at the bottom of each reply
    - this is mandatory and cannot be omitted
  format: |-
    <roleplay_options>
    ```
    ...
    ```
    </roleplay_options>
```

### 2. 在世界书配置中添加条目

在 [`src/佩伊洛/index.yaml`](src/佩伊洛/index.yaml) 的"界面系统"文件夹中，在"选择框"条目之后添加：

```yaml
- 名称: 选择框强调
  启用: true
  激活策略:
    类型: 蓝灯
  插入位置:
    类型: 指定深度
    角色: 系统
    深度: 0
    顺序: 14721  # 比"选择框"的14720稍大，确保在其后
  递归:
    不可被其他条目激活: true
    不可激活其他条目: true
  文件: 世界书/选择框强调
```

## 配置说明

### 为什么需要选择框强调？

类似于"下一回合界面选择强调"的设计理念：

1. **"选择框"条目**（顺序14720）：包含完整的选择框规则、格式和选项类型定义
2. **"选择框强调"条目**（顺序14721）：简短强调，提醒AI必须输出选择框

### 位置和深度

- **位置**：D齿轮深度0（D0）
- **原因**：D0是影响力最强的位置，确保AI始终记得输出选择框
- **顺序**：14721（在"选择框"之后），让AI先看到完整规则，再看到强调

### 触发策略

- **蓝灯常驻**：每次回复都需要选择框，必须常驻激活

### 递归设置

- **不可被其他条目激活**：true
- **不可激活其他条目**：true
- 防止TOKEN爆炸

## 预期效果

添加"选择框强调"后：

1. ✅ AI在每次回复末尾都会输出 `<roleplay_options>` 标签
2. ✅ 即使在长对话中，选择框也不会被遗忘
3. ✅ 与"下一回合界面选择强调"形成配套，确保界面系统完整输出

## 注意事项

1. **文件创建**：由于Architect模式只能编辑Markdown文件，需要切换到Code模式创建 `.txt` 文件
2. **同步更新**：创建文件后，记得在 `index.yaml` 中添加对应的条目配置
3. **测试验证**：修改后测试几轮对话，确认选择框每次都正常输出
