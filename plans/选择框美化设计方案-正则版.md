# 选择框美化设计方案（正则替换版）

## 🔍 实现方式分析

通过研究 `galgame角色卡示例`，发现其使用**酒馆正则替换**功能来美化选择框：

### 原理
1. AI输出 `<roleplay_options>` 标签包裹的选项文本
2. 酒馆正则在**仅格式显示**时将标签替换为美化的HTML
3. 用户看到的是美化后的选择框，但实际消息内容保持原始格式

### 配置位置
在角色卡的世界书中配置正则替换规则：
```yaml
- 正则名称: 内嵌选择框标签
  启用: true
  查找表达式: /<(roleplay_options)>\s*(?:```.*\n)?((?:(?!<\1>)[\s\S])*?)(?:\n```)?\s*<\/\1>/mi
  文件: 正则\内嵌选择框标签
  来源:
    用户输入: false
    AI输出: true
  作用于:
    仅格式显示: true  # 只在显示时替换，不影响提示词
    仅格式提示词: false
```

#### 替换模板（需要JavaScript处理）
由于需要动态生成编号和处理多个选项，替换模板需要使用JavaScript：

```javascript
// 在 src/佩伊洛/世界书/正则/内嵌选择框-Galgame.txt
function replaceGalgameChoices(match, content) {
  const lines = content.trim().split('\n').filter(line => line.trim());
  const numbers = ['①', '②', '③', '④', '⑤', '⑥'];

  let html = '<div class="galgame-choices">';
  lines.forEach((line, index) => {
    const [title, text] = line.split(/[:：]/).map(s => s.trim());
    const displayText = text || title;
    html += `
      <div class="galgame-choice" onclick="sendChoice(this)" data-content="${displayText}">
        <span class="choice-number">${numbers[index]}</span>
        <span class="choice-text">${displayText}</span>
      </div>
    `;
  });
  html += '</div>';

  // 添加样式和脚本...
  return html;
}
```

### 步骤3：处理JavaScript逻辑

由于正则替换不支持复杂的JavaScript逻辑，我们需要：

**方案A：使用纯HTML模板（推荐）**
- 在替换文件中直接写死HTML结构
- 使用CSS计数器自动生成编号
- 使用内联onclick处理点击

**方案B：使用脚本辅助**
- 创建一个脚本文件来处理选择框的动态生成
- 正则只负责插入占位符
- 脚本监听DOM变化并替换占位符

## 💡 推荐实现：纯HTML模板

为了简化实现，建议使用纯HTML模板，利用CSS计数器和内联脚本：

### Galgame版本模板
```html
<div class="galgame-choices" data-choices="$2">
  <!-- 选项将由内联脚本动态生成 -->
</div>

<style>
/* CSS样式 */
</style>

<script>
(function() {
  const container = document.currentScript.previousElementSibling;
  const content = container.getAttribute('data-choices');
  const lines = content.trim().split('\n').filter(line => line.trim());
  const numbers = ['①', '②', '③', '④', '⑤', '⑥'];

  container.innerHTML = lines.map((line, i) => {
    const parts = line.split(/[:：]/);
    const text = parts.length > 1 ? parts[1].trim() : parts[0].trim();
    return `
      <div class="galgame-choice" onclick="
        const textarea = document.getElementById('send_textarea');
        textarea.value = '${text.replace(/'/g, "\\'")}';
        textarea.focus();
      ">
        <span class="choice-number">${numbers[i]}</span>
        <span class="choice-text">${text}</span>
      </div>
    `;
  }).join('');
})();
</script>
```
