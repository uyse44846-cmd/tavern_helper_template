# 选择框美化设计预览

## 📋 设计需求

- **Galgame模式**：选择框内嵌在Galgame界面底部，需要融入Galgame视觉风格
- **Sprite模式**：独立显示的选择框，使用渐变边框卡片式设计
- **共同目标**：减少空间占用，提升视觉精致度

---

## 🎮 方案一：Galgame内嵌选择框

### 设计理念
选择框作为Galgame对话框的一部分，位于对话内容下方，采用半透明深色背景与Galgame界面融为一体。

### 视觉效果示意

```

│  │ 佩伊洛                                              │ │
│  │ "今天天气真好呢，要不要一起去公园走走？"            │ │
│  │                                                     │ │
│  │ ┌─────────────────────────────────────────────┐   │ │
│  │ │ ① "好啊，我们一起去吧"                       │   │ │
│  │ ├─────────────────────────────────────────────┤   │ │
│  │ │ ② "抱歉，我今天有点事..."                    │   │ │
│  │ ├─────────────────────────────────────────────┤   │ │
```

### 样式特点

**布局结构：**
- 选择框嵌入在Galgame对话框内部底部
- 与对话内容之间有适当间距（12-16px）
- 选项之间使用细线分隔（1px，半透明白色）

**视觉样式：**
- 背景：`rgba(0, 0, 0, 0.3)` - 深色半透明，不遮挡背景
- 边框：`1px solid rgba(255, 255, 255, 0.1)` - 微妙的边框
- 圆角：`8px` - 与对话框风格统一
- 内边距：`8px` - 紧凑布局

**选项样式：**
- 编号：圆形数字 `①②③`，颜色 `#ffb6c1`（粉色，与角色名颜色呼应）
- 文字：`14px`，颜色 `#f0f0f0`
- 行高：`1.6` - 保证可读性
- 内边距：`10px 12px` - 紧凑但不拥挤

**交互效果：**
- Hover：背景变为 `rgba(255, 255, 255, 0.08)`，编号发光
- Active：轻微缩放效果
- 过渡：`0.2s ease` - 流畅自然

### CSS核心代码

```scss
  }

    color: #f0f0f0;

    line-height: 1.6;

  }
```

## 🎨 方案二：Sprite渐变边框卡片式

### 样式特点

**布局结构：**
- 外层容器：`padding: 12px 0`，`gap: 8px`
- 每个选项独立卡片，紧凑排列
- 标题和内容垂直排列，无分隔线

**视觉样式：**
- 背景：`rgba(255, 255, 255, 0.03)` + `backdrop-filter: blur(8px)` - 玻璃态效果
- 边框：渐变边框效果
  - 左侧：`3px solid` 渐变色条 `linear-gradient(to bottom, #a78bfa, #ec4899)`
  - 其他边：`1px solid rgba(255, 255, 255, 0.1)`
- 圆角：`10px`
- 内边距：`10px 14px` - 比现有减少30%
- 阴影：`0 2px 8px rgba(0, 0, 0, 0.1)` - 轻微浮起感

**文字样式：**
- 标题：`13px`，`font-weight: 600`，颜色 `#f0f0f0`
- 内容：`13px`，`font-weight: 400`，颜色 `#c6c6c6`
- 行高：`1.5`

**交互效果：**
- Hover：
  - 背景变为 `rgba(255, 255, 255, 0.06)`
  - 边框颜色增强
  - 左侧色条发光：`box-shadow: -2px 0 12px rgba(167, 139, 250, 0.4)`
  - 向上移动 `translateY(-2px)`
  - 阴影增强：`0 4px 16px rgba(0, 0, 0, 0.15)`
- Active：轻微回弹
- 过渡：`0.25s cubic-bezier(0.4, 0, 0.2, 1)` - 流畅的缓动

### CSS核心代码

```scss
.roleplay-options {
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 12px 0;

  &-item {
    position: relative;
    background: rgba(255, 255, 255, 0.03);
    backdrop-filter: blur(8px);
    border: 1px solid rgba(255, 255, 255, 0.1);
    border-radius: 10px;
    padding: 10px 14px;
    cursor: pointer;
    transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);

    // 左侧渐变色条
    &::before {
      content: '';
      position: absolute;
      left: 0;
      top: 0;
      bottom: 0;
      width: 3px;
      background: linear-gradient(to bottom, #a78bfa, #ec4899);
      border-radius: 10px 0 0 10px;
      opacity: 0.8;
      transition: all 0.25s ease;
    }

    &:hover {
      background: rgba(255, 255, 255, 0.06);
      border-color: rgba(255, 255, 255, 0.15);
      transform: translateY(-2px);
      box-shadow: 0 4px 16px rgba(0, 0, 0, 0.15);

      &::before {
        opacity: 1;
        box-shadow: -2px 0 12px rgba(167, 139, 250, 0.4);
      }
    }

    &:active {
      transform: translateY(-1px);
    }
  }

  &-title {
    display: block;
    font-size: 13px;
    font-weight: 600;
    color: #f0f0f0;
    margin-bottom: 4px;
    padding-left: 8px; // 为左侧色条留出空间
  }

  &-content {
    display: block;
    font-size: 13px;
    font-weight: 400;
    color: #c6c6c6;
    line-height: 1.5;
    padding-left: 8px;
  }
}
```

## 💡 技术要点

### Galgame内嵌选择框
1. **数据解析**：从 `<roleplay_options>` 标签中提取选项
2. **YAML集成**：在Galgame的YAML数据中添加 `choices` 字段
3. **状态管理**：选择后隐藏选择框，发送用户消息

### Sprite渐变边框选择框
1. **玻璃态效果**：使用 `backdrop-filter: blur()` 需要注意浏览器兼容性
2. **渐变边框**：使用伪元素 `::before` 实现左侧色条
3. **响应式设计**：在小屏幕上调整字体和间距
