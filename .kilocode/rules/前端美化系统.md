# 前端美化系统

当需要通过正则替换来美化AI输出的内容时，应该使用本文件中的前端美化系统模式。

**注意：本文件描述的是"正则替换为代码块HTML"模式，与 webpack 前端界面项目（`src/xxx/index.ts + index.html`）是不同的概念。**

## 什么是前端美化系统

前端美化系统通过酒馆正则定位AI输出中的特定内容，将其替换为前端界面代码块（用 ``` 包裹的完整HTML页面），然后在代码块中通过 `getChatMessages` 获取消息原文，自行解析并渲染为精美的HTML界面。

酒馆会将 ``` 代码块渲染为独立的 **iframe**，因此内部的 `<script>` 标签能正常执行。

## 核心架构

1. **酒馆正则**：定位AI输出中的特定标签区域，将其替换为前端界面代码块
2. **前端界面代码**：在代码块 iframe 中加载，用 `getChatMessages` 获取消息原始内容，自行解析数据，渲染界面

## 重要原则

### 正则只负责定位，不负责传数据

- 正则的唯一任务是找到标签区域并替换为前端界面的代码块
- **禁止**在正则里用 `$1` 捕获并传递数据
- 数据获取在前端界面代码中通过 `getChatMessages` 完成

### 禁止使用的标签（会导致系统错误）

- `<think>`
- `<thinking>`
- `<content>`

### 不能使用 `<img onerror>` 或裸 `<script>` 内嵌在正则替换HTML中

酒馆的HTML清理机制会阻止内嵌在消息DOM中的 `<img onerror>` 和 `<script>` 执行。
**必须**使用 ``` 代码块方式，让HTML在独立 iframe 中运行。

## 两种模式

### 模式A：正文美化
- AI正常输出文本，只需包在一个标签里
- HTML代码获取原文后，直接美化渲染
- 适合：美化正文排版、对话气泡、信件样式、日记本等

### 模式B：结构化数据美化
- AI输出结构化数据（如 `[字段|值]` 格式、`键: 值` 格式、或自由文本）
- HTML代码获取原文后，解析结构化数据，渲染为功能界面
- 适合：状态栏、论坛、任务系统、商店、角色面板、**选择框**等

## 正则配置

```yaml

查找表达式: <标签名>[\s\S]*?</标签名>
替换为: |-  # 或用 文件: 引用外部txt
  ```
  <!DOCTYPE html>
  <html>..完整HTML..</html>
  ```
来源:
  AI输出: true
作用于:
  仅格式显示: true
  仅格式提示词: false
```

## 代码编写通用规范

1. **数据获取**：必须使用 `getChatMessages(getCurrentMessageId())` 获取消息
2. **注释格式**：仅使用 `/* 注释 */`，**禁止使用 `//` 注释**（会导致渲染失败）
3. **加载时机**：使用 `$(function() { init(); });` 而不是 `DOMContentLoaded`
4. **高度适配**：禁止使用 `vh` 单位，使用 `width` 和 `aspect-ratio` 让高度动态调整
5. **背景颜色**：如果样式更适合卡片形状，不要有背景颜色，除非用户明确要求
6. **页面适配**：页面整体应适配容器宽度，不产生横向滚动条
7. 避免使用 `min-height`、`overflow: auto` 等强制撑高父容器的属性
8. 主体内容不能使用 `position: absolute` 等脱离文档流的样式
9. **空值处理**：所有渲染的字段都要有 `|| ''` 或 `|| '默认值'` 的兜底
10. **错误处理**：用 `try-catch` 包裹核心逻辑

## 标准HTML骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <style>
        * { margin: 0; padding: 0; box-sizing: border-box; }
        body { font-family: "Microsoft YaHei", sans-serif; background: transparent; padding: 8px; }
        .container { max-width: 600px; margin: 0 auto; }
        .loading { text-align: center; padding: 20px; color: #999; }
    </style>
</head>
<body>
    <div class="container" id="content">
        <div class="loading">正在加载...</div>
    </div>
    <script>
        /* ========== 获取消息内容 ========== */
        function getMessageData() {
            var chatMessages = getChatMessages(getCurrentMessageId());
            if (!chatMessages || chatMessages.length === 0) return null;
            return chatMessages[0].message;
        }

        /* ========== 解析数据 ========== */
        function parseData(messageText) {
            var match = messageText.match(/<标签名>([\s\S]*?)<\/标签名>/);
            if (!match || !match[1]) return null;
            return match[1].trim();
        }

        /* ========== 渲染界面 ========== */
        function renderPage(data) {
            /* 根据需求构建HTML */
            document.getElementById('content').innerHTML = '渲染结果';
        }

        /* ========== 交互：填入输入框 ========== */
        function fillInput(text) {
            try {
                var input = window.parent.document.querySelector('#send_textarea');
                if (input) {
                    input.value = text;
                    input.dispatchEvent(new Event('input', { bubbles: true }));
                }
            } catch (e) { console.error(e); }
        }

        /* ========== 交互：发送消息并触发AI ========== */
        function sendAndTrigger(keyword, param) {
            if (typeof triggerSlash === 'function') {
                triggerSlash('/send ' + keyword + '：' + param + '|/trigger');
            }
        }

        /* ========== 主函数 ========== */
        function init() {
            try {
                var msg = getMessageData();
                if (!msg) { document.getElementById('content').innerHTML = ''; return; }
                var data = parseData(msg);
                if (data) renderPage(data);
                else document.getElementById('content').innerHTML = '';
            } catch (e) {
                console.error(e);
                document.getElementById('content').innerHTML = '';
            }
        }

        $(function() { init(); });
    </script>
</body>
</html>
```
